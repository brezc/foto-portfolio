# Písma

Na webu (a na GitHubu) jsou:

- `tox-typewriter.ttf`: Tox Typewriter od junkohanhero, zdarma pro osobní použití (viz `Tox-Typewriter-Read-me.txt`). Web je osobní a nekomerční. Pro komerční použití je potřeba koupit licenci u autora.
- `rat-typewriter.ttf`: Rat Typewriter od MagicBear (FontStruct), Open Font License.
- `XTypewriter-Regular.ttf`: X Typewriter od GGBotNet, SIL Open Font License 1.1 (viz `XTypewriter-License.txt`).

Složka `nezverejnovat/` je v `.gitignore` a na GitHub se nenahraje:

- Uncle Typewriter (German Olaya): zakazuje dávat písmo na web ke stažení bez svolení autora, jinak ho dovoluje použít na cokoli. Jméno „bea krä“ v hlavičce je z něj proto vyrobené jako vektorové logo (`npm run logo`), samotný soubor písma na webu není.
- Orange Typewriter (Lukas Krakora): autor žádá písmo dál nešířit.
